# 網頁版更新紀錄

網頁版（`docs/`）的版本獨立於 App：更新網頁不會動到 App 的版本號與 App 內的更新紀錄。
目前版本顯示在網頁的「設定」頁。

## v1.3

- **新增**：家庭頁（人生），五個分頁：
  - **成員**：依「我的家／配偶的家」分組，顯示角色、年齡、生日與星座、結婚年數、備註，
    以及兒女紀錄／疫苗／家庭事件／日常紀錄／約定的數量，家庭事件可展開。
  - **兒女紀錄**：每位小孩的紀錄分類統計、身高體重雙軸成長曲線，
    以及疫苗、過敏、成長、就醫（含體溫）、教育、才藝、紀念時刻的完整時間軸。
  - **家庭待辦**：進行中／已完成，顯示負責的家庭成員、截止日與逾期天數。
  - **寵物**：種類、品種、年齡、體重、備註與健康紀錄。
  - **人際關係**：依家人／朋友／同事／客戶／其他分組，含生日、紀念日、電話與互動紀錄。
- **新增**：行事曆納入家庭資料（比照 App）：家庭成員與寵物、人際關係的生日、
  結婚與關係紀念日、家庭待辦的截止日。
- 新增讀取 `kv_life_family`、`kv_life_relationships`、`kv_life_pets`、`kv_life_family_tasks`。
- **修正**：標籤式小列表的樣式原本只在名片頁生效，家庭卡片上標籤與內容會黏在一起。

## v1.2

- **新增**：履歷頁（人生）。個人檔案看板（姓名、公司、職稱、配偶、年資）、里程碑／職涯異動／
  目前薪資／兼任職務四個 KPI、薪資歷程折線圖、職涯時間軸（入職／升職／調薪／轉職／降職／離職，
  含部門職稱職等、調薪前後與漲幅、管理職與管理單位、心情與未來規劃），
  以及全部里程碑依年份分組並可依分類篩選；財富類里程碑可跳到財富卡片，兼任職務可跳到工作區。
- **新增**：部門職等頁（人生・職涯）。職等職稱表附使用人數與使用者（可點到部屬）、
  未設定職等的部屬提醒；部門表附功能、成員數、設備數、主管與上下游／平行部門連結。
- 新增讀取 `kv_life_profile`（個人檔案）。

## v1.1

- **修正**：視窗寬度在約 1100px 以下時，含寬表格的頁面（固定支出、股票、部屬列表、儲蓄險等）
  會把整個版面撐開、出現整頁橫向捲軸。根因是側欄佈局的內容欄預設不能收縮到內容寬度以下；
  改為可收縮並讓寬內容只在自己的卡片內捲動。窄視窗下 KPI 與雙欄區塊也會更早換行。
- **新增**：名片頁（人生・職涯）。可搜尋姓名／公司／職稱／電話／Email，依公司篩選，
  依新增日期／姓名／公司排序；卡片顯示職稱、部門、公司、電話、Email、地址、主要業務，
  並標示是否已連結組織人員或部屬。點入看完整聯絡資訊（電話可撥、Email 可寄、地址可開地圖）、
  備註與同公司的其他名片。
- **新增**：設定頁顯示網頁版本號。

## v1.0

首個版本，含：我的行事曆、部屬總覽／列表／明細、人才矩陣、統計圖表、公司組織與部門、
設備詳細、兼任職務、收支五頁、理財六頁、財富卡片、設定；CloudKit JS 登入與每 10 分鐘自動更新。
